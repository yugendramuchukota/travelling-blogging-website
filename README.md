# TravelSource — Basic Travel Website

A responsive beginner-friendly travel website about popular Indian destinations.

## Included
- Famous destination cards
- Atmosphere/vibe descriptions and visual meter
- Budget, mid-range and luxury average daily expense estimates
- Destination/category filters
- Trip cost calculator
- Responsive mobile layout
- No framework or installation required

## How to run
1. Unzip the folder.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Edit `script.js` to add more destinations or change costs.

## Expense note
The figures are approximate planning estimates in INR per person per day. They can vary by season, hotel choice, transport, activities and booking time.

Example reference used while creating the sample data:
- Ministry of Tourism, Government of India: https://tourism.gov.in/
- YatraPlan India budget calculator: https://yatraplan.com/budget-calculator
- JustArrived India travel budget: https://justarrived.in/budget

The website itself does not make live booking or price guarantees.
